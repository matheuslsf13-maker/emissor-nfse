Como uma pessoa é reconhecida

Quando chega um relatório novo, cada cadastro é comparado assim:

1. Mesmo CPF/CNPJ válido É a mesma pessoa. Dados atualizados por cima.
2. Mesmo nome + nascimento Também é a mesma pessoa — é isso que permite reconhecer alguém cujo CPF foi corrigido no TechCare. Sem essa regra, corrigir um CPF inválido criaria um cadastro novo e o errado ficaria para sempre.
3. Nenhum dos dois Entra como pessoa nova.
